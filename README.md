# trimspan

Trim and reshape span text streams with deterministic transforms.

**Site:** https://theworker02.github.io/trimspan/

## Install / run

```bash
git clone https://github.com/theworker02/trimspan.git
cd trimspan
node src/cli.js
node --test
```
